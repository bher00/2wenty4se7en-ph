Privacy policy

Last updated: November 13, 2026

2wenty4se7en is a private office tool used by one small team. This policy explains what it does with data from Google.

What it accesses

The tool signs in with the team's own Google account and asks for two permissions:

  • Google Sheets (spreadsheets), to read the closers' call sheet and to write approved changes to the team's status sheet. It only opens those two spreadsheets.
  • Google Drive metadata (drive.metadata.readonly), so Google Drive can tell it when the call sheet changes. It doesn't read the contents of any Drive file through this permission.

It doesn't access email, contacts, calendars or any other Google data.

What it stores

  • A copy of the call sheet's rows, which each check compares the sheet with to find what changed.
  • The changes it found, and what was approved and written to the status sheet.
  • The sign-in token that lets it reach the two spreadsheets without signing in again.

This is kept in the team's own database and is only shown to the team. Each new copy replaces the last one, so old copies aren't kept.

Sharing

Data from Google isn't sold, shared with anyone outside the team, used for advertising, or used to train AI models. It's only used to show the sheet's changes to the team and to update the team's status sheet.

2wenty4se7en's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google account's Third-party apps & services page. To have the stored data deleted, contact the address below.
